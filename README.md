# 🌍 Travel Destination Website

A simple frontend travel website project created using HTML, CSS, and basic JavaScript.

This project was developed as a semester-end Web Development project for BCA.

## ✨ Features

* Responsive navigation bar
* Hero section with travel background image
* Popular destinations cards
* Booking/Inquiry form
* Simple JavaScript alert on form submission
* Hover effects using CSS
* Footer with LinkedIn button

## 🛠 Technologies Used

* HTML
* CSS
* JavaScript

## 📂 Project Structure

```plaintext
Travel-Website/
│
├── index.html
├── style.css
├── script.js
└── images/
```

## 🚀 How to Run

1. Download the project
2. Open the folder
3. Run `index.html` in browser

## 📌 Purpose

This project was created for learning and practicing frontend web development basics like:

* Semantic HTML
* CSS Flexbox
* UI Design
* Hover Effects
* Basic JavaScript
